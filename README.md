# APEX Fitness Studio — Demo de portafolio (OLIVION)

Sitio demo genérico de portafolio (rubro: gimnasio/fitness). Marca, logo, dirección y teléfonos son ficticios — no corresponde a ningún gimnasio real. Los servicios (musculación, cardio, clases grupales, nutrición, cafetería, suplementos, duchas/saunas, casilleros, estacionamiento) están inspirados en la oferta típica de un gimnasio real, sin copiar identidad de nadie.

## Contenido
- `index.html` — Home con hero, estadísticas, por qué elegirnos
- `servicios.html` — Entrenamiento + todos los servicios adicionales
- `planes.html` — 3 planes de membresía con precios de ejemplo
- `contacto.html` — Formulario + datos de contacto ficticios
- Fotos reales de gimnasio (Wikimedia Commons, licencia libre) usadas como muestra visual genérica

## Uso
Pieza de portafolio para mostrar a prospectos del nicho gimnasios/fitness. Si se retoma para un cliente real, reemplazar nombre/logo/teléfonos/dirección/precios por los datos reales de ese negocio.
